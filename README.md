## Build docker image

```bash
docker build -f Dockerfile/Dockerfile -t your-image-name .
```

- ### 啟動容器

```bash
docker-compose up -d
```

- ### 進入容器進行操作

```bash
docker-compose exec web bash
```

- ### 停止容器

```bash
docker-compose down
```
